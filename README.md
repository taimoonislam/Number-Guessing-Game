
# ✦ Number Quest — Crack the Code

Number Quest is a desktop number guessing game built with Python and Tkinter. Players must unlock a secret vault by guessing a hidden number before their attempts or time run out.

## Features

- Three difficulty levels
- Countdown timer
- Random secret number generation
- Higher/lower feedback
- Guess history and duplicate-guess validation
- Limited hints
- Score and best-score tracking
- Winning streaks
- Unlockable achievements
- Persistent player progress stored locally
- Keyboard support
- Custom dark arcade interface
- No third-party packages required

## Requirements

- Python 3.10+
- Tkinter

## Run Locally

1. Install Python from https://www.python.org/downloads/
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   ```bash
   python main.py
   ```

   On Windows, `py main.py` can also be used.

## How to Play

1. Select Easy, Medium, or Hard.
2. Enter a whole number within the displayed range.
3. Press Enter or click Crack the Code.
4. Use the clues and hints to narrow down the answer.
5. Beat the timer and attempt limit to unlock the vault.
6. Earn achievements and improve your score.
